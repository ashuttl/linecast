# The pages

The README says what linecast does. These pages go further, one subject each.

- [gallery.md](gallery.md) — the apps in more of their states: other languages and traditions, the radar's themes and layers, small windows, the globe and the sky turned by hand.
- [languages.md](languages.md) — the languages, their regional variants, what each changes, and Persian and right-to-left text.
- [configuration.md](configuration.md) — where settings and caches live, and the environment variables.
- [sources.md](sources.md) — for each kind of data, what is asked first, what stands in, what linecast computes itself, what that was checked against, and the credits.
- [calendars.md](calendars.md) — the traditional calendars the moon can show, how each is computed, and what it was checked against.
- [hours.md](hours.md) — the traditional hours the sunshine view can read the day in, and how each is checked.
- [cultures.md](cultures.md) — the twenty-two sky cultures besides the IAU's, with their sources and credits.

For anyone changing linecast:

- [architecture.md](architecture.md) — where the code for each part lives and how the parts talk to each other.
- [persian-and-rtl.md](persian-and-rtl.md) — the design brief for Persian and right-to-left text, with notes on each terminal and what is still open.

The star catalogues' own notes stay beside the data they describe, in [src/linecast/data/STARS.md](../src/linecast/data/STARS.md).
